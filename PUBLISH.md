# ALTERA – GitHub-startpakke

Dette er en enkel publiseringspakke for ALTERA - Another Life, beregnet for publisering med GitHub Pages.

## Innhold
- `index.html`
- `style.css`
- `script.js`
- `README.md`

## Steg 1 – Opprett ALTERA på GitHub
1. Åpne GitHub i Safari eller nettleseren.
2. Gå til: https://github.com/new
3. Logg inn hvis du blir bedt om det.
4. Fyll inn repository-navn, for eksempel: `altera-another-life`
5. Velg `Public` for gratis GitHub Pages.
6. Trykk `Create repository`.

## Steg 2 – Last opp spillet
1. I GitHub-prosjektet velger du `Add file` → `Upload files`.
2. Last opp filene fra denne pakken.
3. Skriv en commit-melding, for eksempel: `Legg til ALTERA landing page`.
4. Trykk `Commit changes`.

## Steg 3 – Aktiver nettsiden
1. Gå til `Settings` → `Pages`.
2. Velg:
   - `Deploy from a branch`
   - Branch: `main`
   - Folder: `/(root)`
3. Trykk `Save`.

Da vil nettadressen normalt få dette formatet:
https://DITT-BRUKERNAVN.github.io/altera-another-life/

Det kan ta noen minutter før siden blir tilgjengelig.

## Viktig
Dette publiserer den nettbaserte testversjonen. Ekte flerspillerfunksjoner og spillserveren trenger en separat serverløsning, som vi kan sette opp senere på Render.
