# ALTERA - Another Life

En enkel GitHub Pages-startpakke for prosjektet ALTERA - Another Life.

## Innhold
- `index.html` – nettside/landing page
- `style.css` – stil og layout
- `script.js` – liten interaktiv oppførsel
- `PUBLISH.md` – publiseringsguide for GitHub Pages

## Publisering på GitHub Pages
1. Opprett et nytt GitHub repository.
2. Last opp disse filene i repoet.
3. Gå til Settings → Pages.
4. Velg:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/(root)`
5. Trykk Save.
6. Vent noen minutter, så blir siden tilgjengelig på:
   https://DITT-BRUKERNAVN.github.io/altera-another-life/

## Merknad
Dette er den nettbaserte testversjonen. Ekte flerspillerfunksjoner og spillserver trenger en separat serverløsning, for eksempel Render.
